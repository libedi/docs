# 리뷰 도입 단계 설정

메인(오케스트레이터)이 findings를 처리할 때 읽는 설정이다. 절차는 `review-workflow.md`에 있고, 여기는 바뀌는 값만 둔다.

- 현재 단계: 1 (리포트만)
- 차단 대상 check: 없음
- 비교 리뷰어: `task-reviewer-glm` (태그 `glm`). 1단계 동안 태스크마다 기본 리뷰어 다음에 같은 입력으로 호출한다. 결과는 수정 루프에 쓰지 않는다.

## 단계 바꾸기

- 2단계로 올릴 때: 채택률이 확인된 check를 "차단 대상 check"에 적는다. 예: `TR-2, FR-1`
- 차단 대상에서 내릴 때: 해당 check를 지운다.
- 비교를 끝낼 때: "비교 리뷰어" 줄을 지운다.

## 위험도 (제안, 브레인스토밍 스킬 연계 전)

requirements.md 맨 위에 `risk: high`가 있으면 단계와 상관없이 다음을 적용한다.

- FR-2를 차단 대상 check로 다룬다.
- 최종 확인 HTML에 "이음새 코드 직접 확인" 질문을 넣고, FR-2가 본 위치 목록을 함께 보여준다.
